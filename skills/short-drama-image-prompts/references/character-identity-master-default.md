# 默认人物身份四视图母版

## 模板 ID

`character-identity-master`

## 来源与适用范围

本文件同步自导演工作台的
`模板注册表/角色身份母版模板_V1.md`，作为本地短剧 skill 的默认人物身份母版参数。
它只用于建立角色唯一身份锚点，不用于剧情动作、表演状态或场景镜头；造型变体继续使用
`character-look-master` 的边界。

项目已经确认的角色事实、视觉方向和创作者明确覆盖优先于本默认模板；默认模板不得替角色
补造年龄、五官、体型、服装、配饰或声音。

## 固定规格

- 默认生产投影为 RunningHub G2 文生图，默认清晰度为 4K；本 skill 只写提示词，不调用供应商，
  实际生产仍由 `$short-drama-produce` 按项目已确认的生产配置执行。
- 默认建议横向 16:9；实际尺寸和文件格式以供应商返回结果与用户选定候选为准，不把
  `3840×2160`、PNG、指纹或登记一致性作为图片准入硬门槛。
- 使用真人影视短剧质感：真实成年演员外观、真实皮肤纹理和自然人体比例；禁止 2D 插画、
  动漫、卡通、二次元、塑料感、玩偶感、游戏角色感、CG 渲染感和 3D 建模感。
- 同一张无缝一体画布自然排列四个视角：
  - 左侧：正面全身身体视图，从锁骨以下开始裁切，只显示肩部以下身体直至脚部；
  - 中间：背面全身身体视图，从锁骨以下开始裁切，只显示肩部以下身体直至脚部；
  - 右上：正面头部近景；
  - 右下：右 45 度头部近景。
- 左侧和中间不得出现头部、脸部、下巴、耳朵、头发或颈部；右上和右下仅显示头部与肩部。
- 使用中性摄影棚背景和柔和均匀光线。
- 无文字、无 Logo、无水印、无边框、无剧情场景；禁止横线、竖线、分隔条、拼贴缝、卡片
  边界、留白和白边，也不得绘制三等分线或任何版块边界。

## Prompt 必填

角色姓名、年龄感、身份、脸型、五官、肤色、发型、体型、服装、鞋子、固定配饰、材质，
以及“四视图属于同一人物”的声明。所有身份事实必须能追溯到项目视觉设定、剧本、创作者
提供的参考或已批准资产。

### 身份细节清单

五官：脸型骨相、眉形细节、眼型与眼窝、瞳色与反光、鼻梁山根、唇形与唇色、下颌线条、
耳廓耳型、标志性特征、面部肌肉与肤色。

服装材质：面料类别、编织与表面纹理、垂坠受力与硬挺度、战损/污损/做旧细节、金属与扣具
光泽、缝纫与剪裁工艺。

缺少来源的字段标为 `creator_decision_needed` 或项目规定的待确认状态，不由模板补猜。

## 镜头边界与参考图规则

- 瞬时表情、姿势、视线和手部动作属于镜头，不写成新的身份资产。
- 新角色不得引用无关角色图。
- 已有角色的新造型必须改用 `character-look-master`，并引用已批准的身份母版。
- 候选图仍是候选图；只有创作者选定候选后，才可登记为正式身份母版。

## 验收

四个视角必须属于同一人物、同一发型、同一体型和同一套服装；左侧和中间只能显示锁骨以下
身体直至脚部，右上和右下只能显示头部与肩部；整张图必须是无缝一体画布，禁止分隔线、
边框、留白、白边、文字和水印。此模板固定的是人物身份板版式与约束，不代替创作者对候选
人物的人工选择。
