# 默认场景空间母版模板

## 模板 ID

`scene-space-master`

## 来源与适用范围

本文件同步自导演工作台的
`模板注册表/场景空间母版模板_V1.md`，作为本地短剧 skill 的长期复用场景/空间默认生图模板。
它建立可跨镜头或跨集重复使用的地点空间锚点，供镜头状态图和视频连续性引用；不用于一次性
镜头场景、剧情动作或人物身份。

项目已经确认的地点、View、时间/天气/光态和创作者明确覆盖优先于本默认模板；默认模板不得
替地点补造门窗、入口、设备、文字或事故。

## 资产生命周期

本模板只允许长期复用场景进入独立母版流程。只出现一两次的临时场景不建立独立场景母版，
改在视频配方中使用 `referenceDecisions.mode: "prompt_only"`，并在 Prompt 中固定空间、光线、
色调和摄影轴线。

## 固定规格

- RunningHub G2 文生图。
- 默认 4K 横向 16:9，目标 `3840×2160`。
- 只表现单一空间，不拼接不同地点。
- 画面清晰呈现入口、主要空间锚点、光源方向和纵深。

## Prompt 必填

地点与子区域、固定结构、门窗/家具/设备、时间、天气、光源位置、主色调、摄影机高度和轴线、
屏幕左右关系。

## 参考图规则

场景参考只锁定空间布局、光线和色调，不决定人物身份、表演、对白或动作。

## 候选与验收

候选次数允许 1—12 张；超过 1 张必须由创作者选择唯一场景母版。所有候选在选择前不得被
下游当作正式参考。

验收要求：空间结构可辨认、机位轴线明确、无多余地点、无文字、无 Logo、无水印；后续镜头
不得擅自改变固定锚点。
