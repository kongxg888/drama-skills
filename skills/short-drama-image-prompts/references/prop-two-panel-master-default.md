# 默认道具二宫格母版模板

## 模板 ID

`prop-two-panel-master`

## 来源与适用范围

本文件同步自导演工作台的
`模板注册表/道具二宫格母版模板_V1.md`，作为本地短剧 skill 的长期复用关键道具默认生图模板。
它建立道具的形状、材质、纹样和可见状态锚点；不把持有人、剧情动作或临时状态误写成道具身份。

## 资产生命周期

本模板只允许长期复用关键道具进入独立母版流程。只在本集或镜头内出现一两次的道具不建立
独立道具母版，改在视频配方中使用 `referenceDecisions.mode: "prompt_only"`，并在 Prompt 中固定
外观、材质、位置、用途和禁用项。

## 固定规格

- RunningHub G2 文生图。
- 默认 4K 横向 16:9，目标 `3840×2160`。
- 严格二宫格：左侧正面/主要使用面，右侧 45 度或细节面。
- 中性背景、均匀光线。
- 无文字、无 Logo、无水印；若上游明确要求可读文字，必须按文字政策单独处理。

## Prompt 必填

道具名称、用途、形状、尺寸比例、材质、颜色、纹样、磨损、正面状态、45 度细节状态，
以及“两个视图为同一道具”的声明。

## 参考图规则

普通道具默认不引用人物图。已有道具变体必须引用已批准道具母版，并且只改变明确登记的变化项。

## 候选与验收

候选次数允许 1—12 张；超过 1 张必须由创作者选择唯一道具母版。所有候选在选择前不得被
下游当作正式参考。

验收要求：两个视图必须是同一道具；形状、材质、纹样和比例一致；无额外道具、无品牌、无文字
和无水印。
